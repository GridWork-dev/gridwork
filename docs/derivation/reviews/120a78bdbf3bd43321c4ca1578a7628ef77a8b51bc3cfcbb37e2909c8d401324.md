# Second-reader record

## Scope

Twelve gated paths, eleven of them marker-owing plus the systemd unit. This is the
attach hookup: the host stops holding its sessions locally and starts publishing them.
`crates/gwk-pty-host/src/publish.rs` is new — one forwarding task per session on its own
outbound kernel connection, seeding a snapshot from a fresh local attach, forwarding
every live delta batch, retiring on session end, and answering any break (connect
failure, staleness, local broadcast lag) by reconnect-and-reseed, with a `validation`
refusal alone treated as deterministic and fatal; it also owns the operator's session
declarations (`GWK_PTY_HOST_SESSIONS`, parsed whole-or-not-at-all, with a blank-frame
byte-budget check mirroring the kernel's). `src/main.rs` now starts every declared
session, spawns a publisher per session, and stops both halves boundedly at shutdown;
`src/registry.rs` gains a standalone `Attacher` handle so a publisher's attach never
holds the shared registry lock; `src/kernel_client.rs` gains the three typed publish
verbs and skips the wire's two new stream frames; `src/wire.rs` gains a fixture note on
one test; `src/lib.rs`, `envelope.rs`, `ingest.rs`, `logging.rs` update crate docs and
repair a stale in-repo pointer; the unit file re-tunes its hardening for real engine
children. In `crates/gwk-pty/`, `src/session.rs` gains a `POSIX-TERM` marker on `kill`
and `tests/style.rs` rewords its two SGR-58 markers — the three sites the previous
record's findings named. The branch also touches kernel wire, domain protocol, contract
goldens, xtask and site files; those are outside the gated set and outside this record.
